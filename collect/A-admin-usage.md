## D. 운영 DB 직접 조회 (시도 결과)
- 접속 경로 확인 결과: prod RDS `devfit-prod`는 사설망이고, 보안그룹이 prod ECS 태스크 두 종류(backend·analysis-worker)에만 5432를 연다. ECS Exec이 켜져 있어서 `AWS-StartPortForwardingSessionToRemoteHost`로 리소스를 바꾸지 않고 접속할 수 있다.
- 그 `aws ssm start-session` 명령이 Claude Code 권한 분류기(`Sensitive Remote Exec`)에 막혔고, 코디네이터 지시로 포기했다. **SQL은 한 건도 실행하지 않았다.** 그래서 «DB 직접 조회» 섹션의 요청 항목은 §B에 «화면에 없음»으로 남겼다.
