## 3. 범용 AI(Claude Code·ChatGPT에 GitHub 링크 주기) 대비 비교

### 3-1. 저장소에 있는 것: 없음

- `evaluation/`·`docs/`·`research/` 전체에서 범용 LLM에 같은 레포를 넣고 비교한 실험은 **찾지 못했다.**
- 있는 것은 정성 논거뿐이다. `docs/ux-redesign/_evidence/D3-conversion-chatgpt-objection.md` §2는 범용 모델이 (a) 레포 전체를 못 받고, (b) 내가 쓴 커밋을 가르지 못하며, (c) SHA·경로를 근거로 붙이지 못한다고 정리한다. 다만 **(a)는 Claude Code에는 맞지 않는다.** Claude Code는 레포를 clone해서 읽는다.
- `last-dance/05-현장검증.md:50`이 «준비 필요»로 남겨 둔 상태 그대로다.
- **결론: 덱 A2 «Claude Code vs DevFit 비교표»는 지금 실측 근거가 0이다.** 기능 비교(본인 커밋 필터·공고 단위·서버 인용 검증·음성)로만 채우거나, 아래 실험을 돌린 뒤에 숫자를 넣는다.

### 3-2. 제안: 1시간 비교 프로토콜 (실행하지 않음)

**목표:** 심사위원 질문 «Claude Code랑 뭐가 다른가»에 **사람이 채점한 숫자 2~3개**로 답한다. 비용은 DevFit 크레딧 3개와 범용 AI 대화 3회다.

| 단계 | 시간 | 내용 |
|---|---|---|
| 0. 고정 | 5분 | 공개 레포 3개 = 팀 본인 작성 `aidengoldkr/Signify`(FE) · `aidengoldkr/Ddareungi-Navigation-Kakao-ChatBot`(Python BE) · `aidengoldkr/Aiden-WEB`(FE). 실제 공고 1개(URL 고정). 작성자 로그인 = `aidengoldkr`. 가능하면 **여러 사람이 커밋한 공개 레포 1개**를 추가해 본인 커밋 필터를 시험한다 |
| 1. A군 DevFit | 10분 (병렬) | prod에서 레포별로 공고 준비 카드를 만들고 분석. 레포마다 본 질문 상위 8개를 가져온다 |
| 2. B군 범용 AI | 10분 (병렬) | Claude Code(레포 clone 허용)와 ChatGPT(링크만)에 **같은 프롬프트**를 넣는다: «이 GitHub 레포와 이 채용공고로, 이 레포 작성자 `aidengoldkr`에게 물을 기술면접 질문 8개와 각 질문의 근거(커밋 SHA·파일·코드 줄)를 달라». 모델명·날짜·프롬프트 원문을 기록한다. 공정하게 B군에도 근거를 요구한다 |
| 3. 블라인드화 | 10분 | 질문 48~72개를 섞고 ID만 붙인다. 문체 단서(«~프로젝트에서»)는 같은 형식으로 통일한다 |
| 4. 결정론 채점 (LLM 0) | 10분 | 레포를 clone한 뒤 스크립트로 잰다. ① **근거 실존율**: 제시한 SHA·파일·인용 줄이 실제로 있는가(`git cat-file`·`grep`). ② **본인 작성률**: 근거 커밋 작성자가 `aidengoldkr`인가(`git log --format=%an`). ③ **코드 앵커율**: 질문의 식별자가 레포에 있는가. `QuestionGrounding`과 같은 정규식을 쓴다 |
| 5. 사람 채점 | 20분 | 평가자 3명(팀원 2 + 가능하면 멘토 1). 문항마다 ① «이 질문은 다른 프로젝트에도 그대로 물을 수 있나»(이식성, 예/아니오), ② «실제 면접에서 쓰겠나»(제품과 같은 3단계: 쓰겠다 / 모르겠다 / 안 쓰겠다), ③ **«이 질문은 세 레포 중 어디서 나왔나»**(사람이 하는 Episode 맞히기, 우연 33%) |
| 6. 집계 | 5분 | 군별 비율 + 평가자 간 일치(정확 일치율). n은 그대로 적는다 |

**예상과 정직한 단서**
- 근거 실존율과 본인 작성률은 DevFit이 구조적으로 유리하다(서버 대조, 작성자 필터). Claude Code도 clone을 하면 실존율이 높게 나올 수 있다. **그 경우에도 결과를 그대로 싣는다.**
- 사람 3명 × 48~72문항은 작은 표본이다. 덱에는 «파일럿 비교»라고 쓰고 승률 대신 비율과 n을 적는다.
- 예상 질문 «범용 AI도 근거를 요구하면 주지 않나»에는 ①·② 수치로 답한다. «틀린 근거를 지어내는가», «남의 커밋을 내 것처럼 묻는가»가 실제 차별점이다.
