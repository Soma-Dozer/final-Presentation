GitHub는 최소 권한으로 연결하고, 토큰과 세션은 원문을 남기지 않음

최소 권한 연동기본 권한은 read:user, user:email뿐. 비공개 레포는 원할 때만 추가 동의, 분석할 레포는 사용자가 선택
토큰 암호화GitHub access token은 AES-256-GCM으로 저장. 운영은 키가 없으면 서버가 기동하지 않음
세션 해시세션 토큰은 SHA-256 해시만 저장하고 HttpOnly 쿠키로 전달. 서버에서 즉시 폐기 가능
SSRF 차단공고 수집은 SafeFetcher로만. 리다이렉트마다 허용 호스트를 다시 검사, 응답 8MB 상한
분석 도구 마스킹Clarity는 화면 전체 마스킹, Sentry는 개인정보 전송과 Replay를 끔
관리자 접근 통제관리자 콘솔은 Cognito TOTP MFA 필수. 관리자의 조회와 변경은 모두 감사 로그로 기록
